# Лабораторная работа №1. Линейная классификация

В рамках лабораторной работы реализуется линейный классификатор для задачи бинарной классификации.

Модель обучается с использованием стохастического градиентного спуска с инерцией, L2-регуляризации и квадратичной функции потерь.

## Датасет

В лабораторной работе используется набор данных **Pima Indians Diabetes Dataset**.

Ссылка на датасет: [pima-indians-diabetes.csv](https://www.kaggle.com/datasets/kumargh/pimaindiansdiabetescsv)

Датасет содержит медицинские показатели пациенток народа Pima и используется для задачи бинарной классификации. Требуется определить, будет ли у пациента диагностирован диабет в течение последующих пяти лет.

Целевая переменная принимает два значения:

- `1` — положительный результат, диабет диагностирован;
- `0` — отрицательный результат, диабет не диагностирован.

### Описание признаков

| Признак | Описание                                                                                             |
| ------- | ---------------------------------------------------------------------------------------------------- |
| `preg`  | Количество беременностей                                                                             |
| `plas`  | Концентрация глюкозы в плазме крови через 2 часа после перорального теста на толерантность к глюкозе |
| `pres`  | Диастолическое артериальное давление, мм рт. ст.                                                     |
| `skin`  | Толщина кожной складки трицепса, мм                                                                  |
| `test`  | Уровень сывороточного инсулина через 2 часа, мкЕд/мл                                                 |
| `mass`  | Индекс массы тела (BMI), кг/м²                                                                       |
| `pedi`  | Функция наследственной предрасположенности к диабету                                                 |
| `age`   | Возраст пациента, лет                                                                                |
| `class` | Целевая переменная: `1` — диабет обнаружен, `0` — диабет не обнаружен                                |

Для признаков `plas`, `pres`, `skin`, `test` и `mass` значение `0` не является корректным медицинским измерением. Нулевая концентрация глюкозы, нулевое диастолическое давление, нулевая толщина кожной складки, нулевой уровень инсулина и нулевой индекс массы тела фактически указывают на отсутствие измерения.

Поэтому такие значения рассматриваются как скрытые пропуски.

Для их обработки нулевые значения заменяются медианой соответствующего признака, рассчитанной только по ненулевым значениям.

Медиана выбрана вместо среднего значения, поскольку она менее чувствительна к выбросам и экстремальным значениям. Это особенно важно для медицинских признаков, распределения которых могут быть несимметричными.
