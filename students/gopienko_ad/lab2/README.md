# Лабораторная работа №1. Метрическая классификация

В рамках лабораторной работы реализуется линейный классификатор для задачи бинарной классификации.

Модель обучается с использованием стохастического градиентного спуска с инерцией, L2-регуляризации и квадратичной функции потерь.

## 1. Датасет

В работе используется **Pima Indians Diabetes Dataset**.

Ссылка на датасет: [Pima Indians Diabetes Dataset](https://www.kaggle.com/datasets/kumargh/pimaindiansdiabetescsv)

Набор данных содержит медицинские показатели пациенток народа Pima. Задача состоит в определении наличия диабета на основе набора медицинских признаков.

Объём датасета составляет **768 объектов** и **8 признаков**.

| Признак | Описание |
| --- | --- |
| `preg` | Количество беременностей |
| `plas` | Концентрация глюкозы в плазме крови |
| `pres` | Диастолическое артериальное давление |
| `skin` | Толщина кожной складки трицепса |
| `test` | Уровень сывороточного инсулина |
| `mass` | Индекс массы тела |
| `pedi` | Функция наследственной предрасположенности к диабету |
| `age` | Возраст |
| `class` | Целевая переменная |

Распределение классов:

| Класс | Количество |
| --- | ---: |
| 0 | 500 |
| 1 | 268 |

Датасет несбалансирован: отрицательный класс составляет приблизительно 65.1% объектов, а положительный — 34.9%.

В признаках `plas`, `pres`, `skin`, `test` и `mass` обнаружены нулевые значения, которые для соответствующих медицинских измерений рассматриваются как скрытые пропуски.

| Признак | Количество нулей |
| --- | ---: |
| `plas` | 5 |
| `pres` | 35 |
| `skin` | 227 |
| `test` | 374 |
| `mass` | 11 |

Нулевые значения заменяются медианами соответствующих признаков, рассчитанными по ненулевым значениям. После обработки выполняется стандартизация признаков. Для margin-based постановки исходные метки классов `0` и `1` преобразуются в `-1` и `+1`.

Данные разделяются стратифицированно на обучающую, валидационную и тестовую выборки в соотношении 70% / 15% / 15%.
